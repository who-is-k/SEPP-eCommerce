# Frontend

React 19 + Vite single-page app for the SEPPe-commerce backend.

Pages: product list, cart, checkout, order confirmation, order history, register and login.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Backend base URLs are set in `src/config.js` (customer 8081, product 8082, order 8083, payment 8084).
